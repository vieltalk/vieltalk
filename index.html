Code Example

Here's a quick example to send your first message with VielTalk:

const VielTalk = require('vieltalk-sdk'); const client = new VielTalk.Client({ apiKey: 'your_api_key_here' }); await client.chat.sendMessage({ roomId: 'room_123', message: 'Hello from VielTalk!', userId: 'user_456' });
